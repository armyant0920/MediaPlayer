🎬 多窗格播放器

把影片拖曳到這裡，或按「＋ 加入影片」
可以一次選取多個檔案，每個檔案會開成一個獨立窗格同時播放
按 ? 查看快捷鍵

操作說明

拖曳檔案到空白處新增窗格
拖曳檔案到某個窗格替換該窗格的影片
雙擊影片在視窗內放大 / 還原
Space / K播放 / 暫停目前窗格
Shift+Space全部播放 / 全部暫停
← →目前窗格倒退 / 快轉 5 秒（加 Shift 為 30 秒）
[ ]目前窗格減速 / 加速
M目前窗格靜音 / 開聲音
Z目前窗格在視窗內放大 / 還原
F目前窗格全螢幕
1–9選取第 N 個窗格
Tab切換到下一個窗格
Delete關閉目前窗格
Ctrl+O加入影片
Esc還原放大 / 關閉此說明

能播放的格式取決於瀏覽器：MP4 (H.264)、WebM、MOV 大多可以；Chrome / Edge 也能播部分 MKV。AVI、WMV、FLV 等舊格式瀏覽器通常不支援，需要先轉檔。

影片只在你的電腦上播放，不會上傳到任何地方。
