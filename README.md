# 多窗格播放器

一次開啟多個影片，各自在獨立窗格中同時播放。

## 使用方式

1. 下載 `index.html`，用 Chrome 或 Edge 開啟（直接雙擊即可，不需要安裝任何東西）。
2. 按「＋ 加入影片」一次選取多個檔案，或直接把影片拖曳進視窗。
3. 每個檔案會開成一個窗格，版面會依視窗大小自動排列。

影片只在本機播放，不會上傳到任何地方。

## 功能

- 多個影片同時播放，版面可選「自動」或固定 1–5 欄
- 每個窗格可獨立播放 / 暫停 / 拖曳進度 / 調整速度 / 循環
- 「一次只出一個聲音」：打開某個窗格的聲音時，其他窗格自動靜音
- 全部播放、全部暫停、全部靜音
- 同步時間：把所有影片跳到目前選取窗格的時間點
- 拖曳檔案到某個窗格可直接替換影片
- 雙擊影片可在視窗內放大，`F` 鍵全螢幕

## 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| `Space` / `K` | 播放 / 暫停目前窗格 |
| `Shift` + `Space` | 全部播放 / 全部暫停 |
| `←` `→` | 倒退 / 快轉 5 秒（加 `Shift` 為 30 秒） |
| `[` `]` | 減速 / 加速 |
| `M` | 靜音 / 開聲音 |
| `Z` | 在視窗內放大 / 還原 |
| `F` | 全螢幕 |
| `1`–`9` | 選取第 N 個窗格 |
| `Tab` | 切換到下一個窗格 |
| `Delete` | 關閉目前窗格 |
| `Ctrl` + `O` | 加入影片 |
| `?` | 顯示快捷鍵說明 |

## 支援格式

能播放的格式取決於瀏覽器本身：

- MP4 (H.264/AAC)、WebM、MOV：大多可以
- MKV：Chrome / Edge 可播放部分檔案（視內部編碼而定）
- AVI、WMV、FLV 等舊格式：瀏覽器通常不支援，需先轉成 MP4

無法播放的檔案會在窗格中顯示提示訊息。
