# MediaPlayer

本專案包含兩個純網頁工具，都不需要安裝，用 Chrome 或 Edge 直接開啟 HTML 檔即可。影片只在本機處理，不會上傳。

| 工具 | 檔案 | 用途 |
| --- | --- | --- |
| 多窗格播放器 | `index.html` | 同時開多個影片，各自在獨立窗格播放 |
| 多語字幕編輯器 | `editor/index.html` | 為影片加上多語言字幕與註解、簡單剪輯、輸出字幕檔或燒好字幕的影片 |

---

## 多語字幕編輯器（`editor/`）

為已取得授權的影片製作多語言字幕與註解，方便推廣到不同語言的觀眾。

> 使用時請保持 `editor/` 資料夾完整（`index.html`、`editor.css`、`editor.js`、`lib/`）。

### 功能

- **字幕**：在目前播放位置新增字幕，邊看邊打字；按 `Enter` 接下一句。可在時間軸拖曳調整時間，或用 `[` `]` 對齊到播放位置。
- **多語言**：每句字幕與註解都可以有多個語言版本，預覽可同時顯示兩種語言（雙語字幕）；清單會標出哪些語言還沒翻譯。
- **註解**：自己加在畫面上的說明文字框，可在預覽畫面直接拖曳位置，並提供多種配色、大小與寬度設定，同樣支援多語言。
- **翻譯（AI 接入前的過渡做法）**：一鍵複製翻譯請求 → 貼到任何 AI 聊天（ChatGPT、Claude…）→ 把回覆貼回來，所有字幕與註解會自動填入對應語言。
- **簡單剪輯**：用入點 / 出點剪掉不要的片段，或只保留某一段；字幕時間會自動跟著調整。
- **匯入字幕**：支援 SRT / VTT；時間對得上的句子會合併成同一句的其他語言版本。
- **輸出**
  - 各語言字幕檔（SRT / VTT），可上傳到 YouTube Studio，讓觀眾自行切換語言。
  - MP4 影片：把字幕（可雙語）與註解燒進畫面，適合 Instagram、TikTok 等平台；可選解析度、畫質與音量。
- **專案存檔**：專案存成 `.json`（不含影片本身），之後開啟專案與影片即可繼續編輯；編輯內容也會自動暫存在瀏覽器中。
- 聲音波形顯示、復原 / 重做、快捷鍵（按 `?` 查看）。

### 目前的限制

- 建議使用最新版 Chrome / Edge；輸出 MP4 需要瀏覽器支援 WebCodecs。
- 能開啟的格式取決於瀏覽器（MP4、WebM、MOV 大多可以；AVI、WMV 等舊格式需先轉檔）。
- 每次處理一支影片；多支影片合併、背景音樂、轉場特效等尚未支援。
- AI 語音辨識（自動產生字幕）與 AI 自動翻譯尚未接入。

### 使用的第三方函式庫

- [Mediabunny](https://github.com/Vanilagy/mediabunny) 1.66.5（MPL-2.0）：影片解碼與 MP4 編碼，檔案位於 `editor/lib/`。

## 多窗格播放器（`index.html`）

1. 用 Chrome 或 Edge 開啟 `index.html`。
2. 按「＋ 加入影片」一次選取多個檔案，或直接把影片拖曳進視窗。
3. 每個檔案會開成一個窗格，版面會依視窗大小自動排列。

### 功能

- 多個影片同時播放，版面可選「自動」或固定 1–5 欄
- 每個窗格可獨立播放 / 暫停 / 拖曳進度 / 調整速度 / 循環
- 「一次只出一個聲音」：打開某個窗格的聲音時，其他窗格自動靜音
- 全部播放、全部暫停、全部靜音
- 同步時間：把所有影片跳到目前選取窗格的時間點
- 拖曳檔案到某個窗格可直接替換影片
- 雙擊影片可在視窗內放大，`F` 鍵全螢幕

### 快捷鍵

| 按鍵 | 功能 |
| --- | --- |
| `Space` / `K` | 播放 / 暫停目前窗格 |
| `Shift` + `Space` | 全部播放 / 全部暫停 |
| `←` `→` | 倒退 / 快轉 5 秒（加 `Shift` 為 30 秒） |
| `[` `]` | 減速 / 加速 |
| `M` | 靜音 / 開聲音 |
| `Z` | 在視窗內放大 / 還原 |
| `F` | 全螢幕 |
| `1`–`9` | 選取第 N 個窗格 |
| `Tab` | 切換到下一個窗格 |
| `Delete` | 關閉目前窗格 |
| `Ctrl` + `O` | 加入影片 |
| `?` | 顯示快捷鍵說明 |

### 支援格式

能播放的格式取決於瀏覽器本身：MP4 (H.264/AAC)、WebM、MOV 大多可以；Chrome / Edge 可播放部分 MKV；AVI、WMV、FLV 等舊格式需先轉成 MP4。無法播放的檔案會在窗格中顯示提示訊息。
