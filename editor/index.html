      YouTube 可以在 YouTube Studio →「字幕」為同一支影片上傳多種語言，觀眾可自行切換，是推廣到多語市場最好的方式。

      影片（字幕、註解直接燒進畫面）

      適合要上傳到 Instagram、TikTok、Facebook 等沒有多語字幕切換功能的平台。每種語言需各輸出一次。

      ＋

      這個字幕檔是什麼語言？

      時間與現有字幕對得上的句子，會合併成同一句的另一個語言版本；對不上的會新增為新的字幕。

      使用說明

      基本流程

      1. 開啟影片（取得授權的檔案）。
      2. 在「字幕」分頁逐句新增字幕：播放到開始的地方按 N，打字，按 Enter 接著下一句。
      3. 用 [ ] 把選取的字幕開始 / 結束對齊到目前播放位置，或在時間軸上直接拖曳。
      4. 在「註解」分頁加上你自己的說明文字框，在畫面上拖曳擺放位置。
      5. 在「語言 / 翻譯」加入要推廣的語言並翻譯。
      6. 「輸出」：下載各語言字幕檔上傳 YouTube，或輸出燒好字幕的 MP4。
      7. 記得「儲存專案」，之後開啟專案和影片就能繼續編輯。

      快捷鍵

      Space播放 / 暫停
      ← →倒退 / 快轉 1 秒（加 Shift 為 5 秒）
      , .倒退 / 前進一格畫面
      ↑ ↓跳到上一句 / 下一句字幕
      N / C在目前位置新增字幕 / 註解
      [ ]選取項目的開始 / 結束設為目前位置
      Enter編輯選取的項目；在字幕文字框中按 Enter 跳到下一句（Shift+Enter 換行）
      I O X設定入點、出點、剪掉區間
      Delete刪除選取的項目
      Esc取消選取 / 清除入出點 / 離開文字框
      Ctrl+Z / Y復原 / 重做
      Ctrl+S / O / E儲存專案 / 開啟影片 / 輸出
      Ctrl+滾輪在時間軸上縮放

      注意事項

      • 建議使用最新版 Chrome 或 Edge。輸出 MP4 需要瀏覽器支援 WebCodecs。
      • 編輯內容會自動暫存在這台電腦的瀏覽器裡，但仍請定期「儲存專案」備份。專案檔不包含影片本身。
      • 能開啟的影片格式取決於瀏覽器：MP4、WebM、MOV 大多可以。
